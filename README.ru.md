# DailyLingo

[English version](README.md)

Личный Telegram-бот для английского (A2–B1) на материалах по вашим интересам.

- ☀️ **Дайджест** каждое утро: 5 статей и подкастов из ваших RSS-лент, отобранных ИИ.
- 📖 **Упростить**: пересказ материала на уровне B1.
- 📚 **Слова**: 10–15 слов и выражений из материала + блок для импорта в Quizlet.
- 🎙 **Обсудить**: разговор голосовыми, исправления после каждой реплики.
- 🗓 **Воскресенье**: разбор ваших типичных ошибок за неделю с упражнениями.

Всё бесплатно: Groq (распознавание речи + LLM), запасной Gemini, озвучка edge-tts, SQLite.

## Файлы
| Файл | Что делает |
|---|---|
| `bot.py` | команды, кнопки, обсуждение, расписание |
| `digest.py` | RSS → текст статьи / начало подкаста |
| `ai.py` | промпты и вызовы Groq / Gemini |
| `tts.py` | озвучка ответов |
| `db.py` | SQLite: материалы и ошибки |
| `net.py` | безопасная загрузка по ссылкам из лент |
| `locales.py` | тексты интерфейса (ru / en) |
| `feeds.txt` | ваши ленты |
| `.env` | ключи и настройки (создать из `.env.example`) |

## 1. Ключи (5 минут)
1. **Бот**: в Telegram напишите @BotFather → `/newbot` → скопируйте токен.
2. **Ваш ID**: напишите @userinfobot, он пришлёт число. Бот будет отвечать только этому ID.
3. **Groq**: console.groq.com → API Keys → Create. Карта не нужна.
4. **Gemini** (по желанию, запасной): aistudio.google.com → Get API key.

## 2. Ленты
Откройте `feeds.txt` и замените примеры своими источниками:
```
psychology | https://example.com/feed
art | https://another-site.com/rss
```
Категория нужна, чтобы дайджест был разнообразным. Подкасты добавляются так же, ссылкой на их RSS.

## 3. Запуск на Windows (для проверки)
```powershell
cd DailyLingo
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env        # вставьте токен, ID и ключи
python bot.py
```
Напишите боту `/start`, затем `/digest`.

## 4. Сервер 24/7 (Oracle Cloud Always Free, Ubuntu)
```bash
sudo apt update && sudo apt install -y python3-venv git
# скопируйте папку на сервер, например: scp -r english-bot ubuntu@<IP>:~
cd ~/english-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
nano .env           # те же значения, что на Windows

chmod 600 .env     # ключи может читать только ваш пользователь
sudo cp english-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now english-bot
journalctl -u english-bot -f    # логи
```
⚠️ Бот должен работать **в одном месте**. Перед запуском на сервере остановите его на компьютере, иначе Telegram выдаст ошибку `Conflict`.

Обновление: скопировать новые файлы → `sudo systemctl restart english-bot`.

## 5. Слова в Quizlet
1. Нажмите на серый блок «Для Quizlet» в сообщении: текст скопируется.
2. Откройте **quizlet.com в браузере** (в приложении для iPad импорта может не быть) → Create → Study set → **Import**.
3. Вставьте текст. В «Between term and definition» выберите **Custom** и введите `|`. Между карточками: **New line**.
4. Назовите набор по материалу и сохраните. Карточки появятся в приложении на iPad.

## Настройки (`.env`)
| Параметр | По умолчанию | Что меняет |
|---|---|---|
| `UI_LANG` | `en` | язык интерфейса: `ru` или `en` |
| `NATIVE_LANGUAGE` | `Russian` | язык переводов и объяснений |
| `TIMEZONE` | `UTC` | ваш часовой пояс, например `Europe/Moscow` |
| `DIGEST_TIME` | `08:00` | время дайджеста |
| `DIGEST_SIZE` | `5` | число материалов |
| `INTERESTS` | `art, medicine, psychology` | что отбирать (можно подробно, через запятую) |
| `REVIEW_DAY`, `REVIEW_TIME` | `sun`, `11:00` | когда разбор ошибок |
| `VOICE_REPLIES` | `1` | `0` — бот отвечает только текстом |
| `TTS_VOICE`, `TTS_RATE` | `en-US-AriaNeural`, `-5%` | голос и скорость |
| `PODCAST_MAX_MB` | `9` | сколько скачивать от выпуска (~10 минут) |
| `GROQ_MODEL`, `GEMINI_MODEL` | см. `.env.example` | модели (имена иногда меняются) |

## Безопасность
Что уже встроено в код:
- бот отвечает только на ваш Telegram ID и только в личном чате;
- ссылки из лент открываются только на публичные сайты: внутренняя сеть сервера и сервис метаданных облака недоступны, каждый редирект проверяется, размер и время загрузки ограничены;
- тексты статей передаются ИИ как «недоверенные данные», а из ответов ИИ вырезаются ссылки и @username, чтобы через бота нельзя было подсунуть фишинг;
- весь вывод экранируется, SQL-запросы параметризованы;
- бот работает через polling: на сервере не нужен ни один открытый порт;
- systemd-сервис изолирован: бот может писать только в свою папку;
- версии библиотек закреплены и проверены `pip-audit`.

Что сделать вам один раз:
1. **@BotFather** → `/setjoingroups` → **Disable**: бота нельзя будет добавить в группы.
2. **Oracle Cloud** → Security List сети: оставить только входящий TCP 22 (SSH), лучше только с вашего IP. Вход только по SSH-ключу (так по умолчанию).
3. На сервере: `sudo apt install -y unattended-upgrades` — автоматические обновления безопасности.
4. `.env` никуда не публикуйте и не коммитьте (он уже в `.gitignore`).

Раз в месяц: `pip install pip-audit && pip-audit -r requirements.txt`. Если найдутся уязвимости, обновите указанные пакеты.

**Если ключ утёк**: токен бота отзывается в @BotFather (`/revoke`), ключи Groq и Gemini удаляются и создаются заново в их консолях. Затем обновите `.env` и перезапустите бота.

**Приватность**: ваши реплики и тексты материалов уходят в Groq, Gemini (бесплатный тариф Google может использовать данные для обучения) и в Microsoft (озвучка). Не обсуждайте с ботом личные медицинские или финансовые данные.

## Ограничения
- Статьи с платным доступом не откроются: бот обсудит их по описанию из ленты.
- Подкаст расшифровывается только по первым ~10 минутам, и только если вы его выбрали.
- Обсуждение хранится в памяти: после перезапуска бота нужно начать его заново.
- Если пришло «Все LLM недоступны», значит закончился лимит бесплатного тарифа. Подождите минуту или добавьте ключ Gemini.
